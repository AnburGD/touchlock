# Touch Lock

Блокировка касаний экрана поверх любого приложения (YouTube, мультики, игры).

## Как получить APK

1. Загрузи все файлы этой папки в новый репозиторий на GitHub (вместе с папкой .github).
2. Открой вкладку **Actions** — сборка запустится сама (около 3–5 минут).
3. Когда появится зелёная галочка, открой **Releases** (справа на главной странице репозитория) и скачай TouchLock-vN.apk прямо на телефон.
4. Установи APK (телефон спросит разрешение на установку из браузера — разреши).

Каждое новое изменение кода → новая сборка → новый APK в Releases. Он ставится поверх старого, удалять приложение не нужно.

## Как пользоваться

- В приложении: «Дать разрешение» → включить «Поверх других приложений».
- «Показать плавающий замок» → на экране появится 🔒 (можно перетаскивать).
- Открой видео, нажми 🔒 — экран заблокирован и не гаснет.
- Разблокировать: дважды нажми на полупрозрачный замок в правом верхнем углу или кнопку в уведомлении.
- PIN-код (по желанию) — после двойного нажатия спросит PIN.
- Забыл PIN — перезагрузи телефон.

Ограничения Android: кнопку питания и системные жесты «Домой/Назад» обычным разрешением заблокировать нельзя (для этого нужен режим «Специальные возможности» — можно добавить в следующей версии).
